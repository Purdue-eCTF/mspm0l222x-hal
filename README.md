# mspm0l222x-hal

This is an [Embedded HAL] (Hardware Abstraction Layer) for the MSPM0L2228 microcontroller from Texas Instruments.

The HAL is built on top of Purdue's fork of the [`mspm0l222x-pac`] Peripheral Access Crate, which provides low-level access to the MSPM0L2228's registers. The HAL provides a higher-level interface to the MSPM0L2228's peripherals, making it easier to write applications.

[`mspm0l222x-pac`]: https://github.com/Purdue-eCTF/mspm0l222x-pac

## Documentation
Documentation for this HAL can be built by running:
```sh
cargo doc --open
```
